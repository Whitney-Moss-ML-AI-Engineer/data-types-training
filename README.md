# Data Types Training

A hands-on training repository for learning how data is classified, represented, measured, transformed, analyzed, visualized, and used in statistics and machine learning.

## Learning Goals

By completing this repository, learners will be able to:

- Identify qualitative and quantitative data.
- Distinguish categorical, numerical, discrete, and continuous variables.
- Apply nominal, ordinal, interval, and ratio measurement scales.
- Understand populations, samples, parameters, and statistics.
- Select probability distributions based on the data-generating process.
- Distinguish parametric, nonparametric, and semiparametric models.
- Select appropriate statistical analyses and visualizations.
- Transform data for statistical and machine-learning models.
- Implement examples in Python.

Each lesson should cover:

2. Characteristics
3. Examples
4. How to identify the data type
5. Mathematical representation
6. Appropriate statistics
7. Appropriate visualizations

9. When to use
10. When not to use
11. Python implementation
12. Exercises
13. Applied challenge

## Recommended Environment

Python, NumPy, pandas, SciPy, Matplotlib, Seaborn, scikit-learn, and statsmodels.
